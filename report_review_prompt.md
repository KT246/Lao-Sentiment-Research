# Senior Report Review Prompt

Act as an international report expert with 20+ years of experience.

Evaluate the following report based on:
- Structure
- Logic
- Depth of insight
- Evidence credibility
- Writing style
- Clarity
- Originality

Give:
1. Quick verdict (Publish-ready / Needs revision / Reject)
2. Top 3 strengths
3. Top 3 critical weaknesses
4. Specific actionable improvements

Be strict and realistic like a senior reviewer.
